## 🏗️ Общая архитектура проекта

Проект представляет собой симуляцию гонок, где нейросети обучаются проходить трассу без столкновений.

### Основные компоненты:

```
┌─────────────────────────────────────────────────────────┐
│                    OptimizedGame                        │
│  (Главный игровой цикл, рендеринг, управление)          │
└─────────────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
┌───────────────┐  ┌────────────────┐  ┌─────────────────┐
│     Track     │  │  Genetic Algo  │  │   Car (50 шт)   │
│  (Трасса +    │  │  (Эволюция +   │  │  (Нейросеть +   │
│   коллизии)   │  │    мутация)    │  │   сенсоры)      │
└───────────────┘  └────────────────┘  └─────────────────┘
                                              │
                                              ▼
                                    ┌─────────────────┐
                                    │ Neural Network  │
                                    │  [8→10→10→2]    │
                                    └─────────────────┘
```

### Поток данных:

1. **Инициализация**: Создаётся популяция из 50 машин с случайными нейросетями
2. **Симуляция**: Каждая машина управляет собой на основе показаний сенсоров
3. **Оценка**: После гибели/финиша вычисляется fitness (приспособленность)
4. **Эволюция**: Генетический алгоритм создаёт новое поколение
5. **Повтор**: Процесс повторяется до достижения хорошего результата

## 🧠 Нейронная сеть

### Архитектура

```
Входной слой (8) → Скрытый слой 1 (10) → Скрытый слой 2 (10) → Выходной слой (2)
     │                    │                     │                    │
  Сенсоры              Tanh                  Tanh              Газ, Поворот
```

### Входные данные (8 нейронов)

Нейросеть получает данные от 8 сенсоров, расположенных вокруг машины:

```
         Сенсор 0
            │
    Сенсор 1 │ Сенсор 7
       ╲     │     ╱
    Сенсор 2 │ Сенсор 6
       ╲     │     ╱
    Сенсор 3 │ Сенсор 5
            │
         Сенсор 4
            │
          [МАШИНА]
```

**Углы сенсоров** (относительно направления машины):
- Сенсор 0: -90° (влево)
- Сенсор 1: -60°
- Сенсор 2: -30°
- Сенсор 3: 0° (прямо)
- Сенсор 4: +30°
- Сенсор 5: +60°
- Сенсор 6: +90° (вправо)
- Сенсор 7: 180° (назад)

**Значение сенсора**: расстояние до стены (от 0.0 до 1.0), где:
- 0.0 = стена очень близко
- 1.0 = стена далеко

### Выходные данные (2 нейрона)

1. **Газ** (tanh от -1 до 1):
   - > 0.1: ускорение
   - < -0.1: торможение
   - около 0: нейтрально

2. **Поворот** (tanh от -1 до 1):
   - > 0: поворот вправо
   - < 0: поворот влево
   - около 0: прямо

### Функции активации

- **Скрытые слои**: ReLU (max(0, x))
- **Выходной слой**: Tanh (гиперболический тангенс)

### Инициализация весов

Веса инициализируются по методу Xavier/He:

```javascript
scale = sqrt(2 / (in_neurons + out_neurons))
weight = random(-1, 1) * scale
bias = random(-1, 1) * 0.1
```

## 🧬 Генетический алгоритм

### Основные параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| Population Size | 50 | Количество машин в поколении |
| Mutation Rate | 15% | Вероятность мутации веса |
| Mutation Strength | 0.3 | Сила мутации |
| Elitism Count | 3 | Количество лучших без изменений |

### Жизненный цикл поколения

```
┌─────────────────────────────────────────────────────────────┐
│                    ПОКОЛЕНИЕ N                              │
│                                                             │
│  1. Создание популяции (50 машин с нейросетями)            │
│         │                                                   │
│         ▼                                                   │
│  2. Симуляция (машины едут, сенсоры читают данные)         │
│         │                                                   │
│         ▼                                                   │
│  3. Оценка fitness (выживание + расстояние + скорость)     │
│         │                                                   │
│         ▼                                                   │
│  4. Сортировка по fitness (от лучшего к худшему)           │
│         │                                                   │
│         ▼                                                   │
│  5. Эволюция (выбор родителей, кроссовер, мутация)         │
│         │                                                   │
│         ▼                                                   │
│  6. Новое поколение → переход к шагу 2                     │
└─────────────────────────────────────────────────────────────┘
```

### Операторы генетического алгоритма

#### 1. Отбор (Tournament Selection)

```javascript
tournamentSelect(population):
    выбрать 5 случайных особей
    вернуть лучшую из них
```

**Преимущества**:
- Сохраняет давление отбора
- Даёт шанс менее приспособленным
- Прост в реализации

#### 2. Кроссовер (Crossover)

```javascript
crossover(parent1, parent2):
    child = clone(parent1)
    для каждого веса в нейросети:
        с вероятностью 50%:
            взять вес от parent2
    вернуть child
```

**Особенности**:
- Равномерный кроссовер (uniform crossover)
- Каждый вес выбирается независимо
- Сохраняет структуру сети

#### 3. Мутация (Mutation)

```javascript
mutate(brain, rate, strength):
    для каждого веса:
        если random() < rate:
            weight += random(-1, 1) * strength
            ограничить weight [-3, 3]
```

**Защита от экстремальных значений**:
- Веса ограничены диапазоном [-3, 3]
- Предотвращает "взрыв" градиентов

## 🎯 Методы обучения

В проекте реализовано **4 метода обучения**:

### 1️⃣ Адаптивная мутация (Adaptive Mutation)

**Принцип работы**:
- Автоматически регулирует силу мутации в зависимости от прогресса
- При застое (stagnation) увеличивает мутацию
- При прогрессе уменьшает мутацию

**Алгоритм**:

```javascript
// Проверка застоя
если (улучшение за 5 поколений < 100):
    stagnationCount++
иначе:
    stagnationCount = 0

// Адаптация силы мутации
если (stagnationCount > 3):
    adaptiveStrength = baseStrength * (1 + stagnationCount * 0.2)
    // Но не более 1.0
```

**Преимущества**:
- Автоматическая настройка параметров
- Выход из локальных оптимумов
- Не требует ручного подбора

**Когда использовать**:
- По умолчанию для большинства задач
- Когда неизвестны оптимальные параметры мутации

---

### 2️⃣ Видообразование (Speciation / NEAT-like)

**Принцип работы**:
- Разделяет популяцию на "виды" по похожести нейросетей
- Каждый вид эволюционирует частично независимо
- Сохраняет разнообразие в популяции

**Алгоритм**:

```javascript
speciate(cars):
    виды = []
    для каждой машины:
        найдено = false
        для каждого вида:
            если distance(машина, представитель) < порог:
                добавить машину в вид
                найдено = true
        если не найдено:
            создать новый вид с этой машиной как представителем
    вернуть виды

distance(brain1, brain2):
    totalDiff = 0
    count = 0
    для каждого веса в brain1 и brain2:
        totalDiff += abs(weight1 - weight2)
        count++
    вернуть totalDiff / count  // среднее различие весов
```

**Эволюция с видообразованием**:

```javascript
evolveSpeciation(cars):
    виды = speciate(cars)
    отсортировать виды по лучшему fitness
    
    // Элитизм от каждого вида
    для каждого вида:
        взять лучшую особь → в новое поколение
    
    // Заполнить остальную популяцию
    пока (популяция не заполнена):
        выбрать вид (пропорционально fitness вида)
        выбрать 2 родителей из вида
        кроссовер + мутация → потомок
```

**Преимущества**:
- Сохраняет генетическое разнообразие
- Позволяет исследовать разные стратегии
- Предотвращает доминирование одного типа

**Когда использовать**:
- Для сложных трасс с множеством решений
- Когда популяция сходится слишком быстро

---

### 3️⃣ CMA-ES (Covariance Matrix Adaptation Evolution Strategy)

**Принцип работы**:
- Продвинутый метод оптимизации
- Поддерживает распределение решений (ковариационную матрицу)
- Адаптирует "шаг" поиска (sigma)

**Упрощённая реализация в проекте**:

```javascript
evolveCMAES(sorted):
    // Инициализация
    если (cmaesMean == null):
        cmaesMean = веса лучшей особи
        cmaesSigma = 0.5
    
    // Обновление среднего
    topCount = min(10, populationSize)
    meanWeights = среднее весов лучших topCount особей
    cmaesMean = meanWeights
    
    // Адаптация sigma
    если (прогресс < 100):
        cmaesSigma *= 1.1  // увеличить шаг
    иначе:
        cmaesSigma *= 0.9  // уменьшить шаг
    cmaesSigma = clamp(cmaesSigma, 0.1, 2.0)
    
    // Генерация новых особей
    пока (популяция не заполнена):
        brain = clone(лучшая особь)
        weights = cmaesMean + gaussian(0, cmaesSigma)
        brain.setWeights(weights)
```

**Гауссово распределение** (Box-Muller):

```javascript
gaussianRandom():
    u = random(0, 1)
    v = random(0, 1)
    вернуть sqrt(-2 * ln(u)) * cos(2 * π * v)
```

**Преимущества**:
- Быстрая сходимость на гладких функциях
- Автоматическая настройка шага поиска
- Хорошо работает в непрерывных пространствах

**Когда использовать**:
- Для точной настройки уже хороших решений
- На простых трассах с одним оптимумом

---

### 4️⃣ Стандартный генетический алгоритм

**Принцип работы**:
- Классический ГА без дополнительных оптимизаций
- Базовая реализация для сравнения

**Алгоритм**:

```javascript
evolveStandard(sorted):
    // Элитизм
    для i от 0 до elitismCount:
        добавить sorted[i].brain.clone() в новое поколение
    
    // Заполнение популяции
    пока (популяция не заполнена):
        parent1 = tournamentSelect(sorted)
        parent2 = tournamentSelect(sorted)
        child = crossover(parent1, parent2)
        child.mutate(mutationRate, mutationStrength)
        добавить child в новое поколение
```

**Преимущества**:
- Простота реализации
- Предсказуемое поведение
- Хорошая базовая линия для сравнения

**Когда использовать**:
- Для обучения и тестирования
- Когда нужна стабильность

## 🏆 Система оценки (Fitness Function)

### Формула расчёта fitness

```javascript
calculateFitness():
    fitness = 0
    
    // 1. Бонус за выживание
    fitness += timeAlive * 2
    
    // 2. Бонус за расстояние
    fitness += totalDistance * 0.5
    
    // 3. Бонус за среднюю скорость
    если (speedCount > 0):
        avgSpeed = speedSum / speedCount
        fitness += avgSpeed * 50
    
    // 4. ОГРОМНЫЙ бонус за финиш
    если (finished):
        fitness += 30000  // базовый бонус
        
        // Бонус за быстрое время
        timeBonus = max(0, (maxTime - finishTime) * 25)
        fitness += timeBonus
        
        // Дополнительные бонусы
        если (finishTime < 300):
            fitness += 15000  // очень быстро!
        иначе если (finishTime < 500):
            fitness += 8000
        иначе если (finishTime < 800):
            fitness += 3000
    
    // 5. Штраф за низкую скорость
    если (timeAlive > 100 и avgSpeed < 1):
        fitness -= 1000
    иначе если (avgSpeed < 2):
        fitness -= 500
    
    вернуть max(0, fitness)
```

### Условия финиша

```
┌─────────────────────────────────────────────────────────┐
│                  УСЛОВИЯ ФИНИША                         │
│                                                         │
│  1. Пройти минимум 75% длины круга                     │
│     (totalDistance >= trackLength * 0.75)              │
│                                                         │
│  2. Находиться в зоне финиша                           │
│     (distance до старта < 40 пикселей)                 │
│                                                         │
│  ОБА условия должны выполняться одновременно!          │
└─────────────────────────────────────────────────────────┘
```

### Почему такая система?

| Компонент | Цель |
|-----------|------|
| Выживание | Поощряет не врезаться |
| Расстояние | Поощряет продвигаться вперёд |
| Скорость | Предотвращает "ползание" |
| Финиш | Главная цель - пройти круг |
| Время | Стимулирует ехать быстрее |
| Штрафы | Наказывает за неэффективное поведение |

## ⚡ Параллельные вычисления

### Worker Pool

Проект использует **Web Workers** для параллельных вычислений:

```javascript
// Инициализация workers
numWorkers = navigator.hardwareConcurrency || 4
workers = []
для i от 0 до numWorkers:
    workers.push(new Worker(workerCode))
```

### Что вычисляется параллельно:

1. **Прямое распространение нейросети** (forward pass)
2. **Кроссовер и мутация**
3. **Оценка популяции** (в ParallelGenetic)

### Преимущества:

- **Ускорение в N раз** (где N = количество ядер CPU)
- **Не блокирует UI** во время вычислений
- **Масштабируемость** на многоядерных системах

## 🎓 Ключевые концепции машинного обучения

### 1. Эволюционные алгоритмы

Проект использует **генетические алгоритмы** - подкласс эволюционных алгоритмов:

```
Популяция → Оценка → Отбор → Размножение → Мутация → Новая популяция
   ↑                                                        │
   └────────────────────────────────────────────────────────┘
```

### 2. Нейроэволюция

Сочетание нейронных сетей и генетических алгоритмов:

```
Нейросеть управляет машиной
     ↓
Генетический алгоритм оптимизирует веса
     ↓
Лучшие веса передаются следующему поколению
```

### 3. Фитнес-функция

Функция приспособленности определяет, насколько хороша особь:

```
Fitness = f(выживание, расстояние, скорость, финиш, время)
```

### 4. Exploration vs Exploitation

Баланс между исследованием и использованием:

- **Exploration** (мутация, видообразование) - поиск новых решений
- **Exploitation** (элитизм, CMA-ES) - улучшение существующих решений

## 📚 Глоссарий

| Термин | Определение |
|--------|-------------|
| **Нейрон** | Базовая единица нейросети, принимает входы, применяет веса, выдаёт выход |
| **Слой** | Группа нейронов, обрабатывающих информацию на одном уровне |
| **Вес** | Параметр, определяющий силу связи между нейронами |
| **Фитнес** | Мера приспособленности особи (чем выше, тем лучше) |
| **Кроссовер** | Оператор скрещивания двух родителей для создания потомка |
| **Мутация** | Случайное изменение весов для внесения разнообразия |
| **Элитизм** | Сохранение лучших особей без изменений |
| **Видообразование** | Разделение популяции на группы по похожести |
