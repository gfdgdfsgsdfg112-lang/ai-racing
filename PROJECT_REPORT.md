## 🎯 Описание проекта

AI Racing - это интерактивное веб-приложение, интегрированное с Telegram, где нейронные сети обучаются проходить гоночные трассы с помощью генетических алгоритмов. Проект демонстрирует применение нейроэволюции для решения задачи автономного управления транспортным средством.

### Ключевые особенности:
- ✅ Самописная нейронная сеть без внешних ML-библиотек
- ✅ 4 различных метода генетического обучения
- ✅ 5 трасс разной сложности
- ✅ Полная интеграция с Telegram Bot API
- ✅ Адаптивный интерфейс для мобильных устройств
- ✅ Система оценки производительности (fitness function)

## 🧠 Техническая реализация

### 1. Нейронная сеть

**Архитектура:**
```
Входной слой (8) → Скрытый слой (10) → Скрытый слой (10) → Выходной слой (2)
```

**Входные данные (8 сенсоров):**
- Сенсор 0: -90° (влево)
- Сенсор 1: -60°
- Сенсор 2: -30°
- Сенсор 3: 0° (прямо)
- Сенсор 4: +30°
- Сенсор 5: +60°
- Сенсор 6: +90° (вправо)
- Сенсор 7: 180° (назад)

**Выходные данные:**
- Выход 0: Газ/Торможение (tanh: -1 до 1)
- Выход 1: Поворот влево/вправо (tanh: -1 до 1)

**Функции активации:**
- Скрытые слои: ReLU (max(0, x))
- Выходной слой: Tanh (гиперболический тангенс)

**Инициализация весов:** Xavier/He initialization
```javascript
scale = sqrt(2 / (in_neurons + out_neurons))
weight = random(-1, 1) * scale
```

**Количество параметров:** ~200 весов и смещений

---

### 2. Генетический алгоритм

**Параметры популяции:**
- Размер популяции: 50 машин
- Элитизм: 3 лучшие особи
- Вероятность мутации: 15%
- Сила мутации: 0.3
- Метод отбора: Tournament Selection (размер турнира: 5)

**Операторы:**

1. **Отбор (Selection):**
   - Tournament Selection - выбор лучшей из 5 случайных особей
   - Сохраняет давление отбора, но даёт шанс слабым особям

2. **Кроссовер (Crossover):**
   - Uniform Crossover - каждый вес выбирается от одного из родителей с вероятностью 50%
   - Сохраняет структуру сети

3. **Мутация (Mutation):**
   - Гауссова мутация с ограничением весов в диапазоне [-3, 3]
   - Предотвращает "взрыв" градиентов

---

### 3. Методы обучения

#### Метод 1: Адаптивная мутация (Adaptive Mutation)
**Принцип:** Автоматическая регулировка силы мутации в зависимости от прогресса

**Алгоритм:**
```
if (улучшение за 5 поколений < 100):
    stagnationCount++
    adaptiveStrength = baseStrength * (1 + stagnationCount * 0.2)
else:
    stagnationCount = 0
```

**Преимущества:**
- Автоматический выход из локальных оптимумов
- Не требует ручной настройки параметров
- Универсальность применения

**Применение:** Рекомендуется по умолчанию для большинства задач

---

#### Метод 2: Видообразование (Speciation)
**Принцип:** Разделение популяции на "виды" по похожести нейросетей

**Алгоритм:**
```
distance(brain1, brain2) = среднее_различие_весов
if distance < порог:
    добавить в существующий вид
else:
    создать новый вид
```

**Преимущества:**
- Сохраняет генетическое разнообразие
- Позволяет исследовать разные стратегии одновременно
- Предотвращает преждевременную сходимость

**Применение:** Для сложных трасс с множеством возможных решений

---

#### Метод 3: CMA-ES (Covariance Matrix Adaptation)
**Принцип:** Продвинутый метод оптимизации с адаптацией шага поиска

**Алгоритм:**
```
cmaesMean = среднее весов лучших 10 особей
if прогресс < 100:
    cmaesSigma *= 1.1  // увеличить шаг
else:
    cmaesSigma *= 0.9  // уменьшить шаг
```

**Преимущества:**
- Быстрая сходимость на гладких функциях
- Автоматическая настройка шага поиска
- Эффективен для точной настройки

**Применение:** Для простых трасс и финальной оптимизации

---

#### Метод 4: Стандартный ГА (Standard Genetic Algorithm)
**Принцип:** Классический генетический алгоритм без дополнительных оптимизаций

**Алгоритм:**
```
1. Элитизм (3 лучших)
2. Tournament Selection
3. Uniform Crossover
4. Gaussian Mutation
```

**Преимущества:**
- Простота и предсказуемость
- Стабильное поведение
- Хорошая базовая линия для сравнения

**Применение:** Для обучения и тестирования

---

### 4. Система оценки (Fitness Function)

**Формула расчёта:**

```javascript
fitness = 0

// 1. Бонус за выживание
fitness += timeAlive * 2

// 2. Бонус за расстояние
fitness += totalDistance * 0.5

// 3. Бонус за среднюю скорость
fitness += avgSpeed * 50

// 4. ОГРОМНЫЙ бонус за финиш
if (finished):
    fitness += 30000  // базовый бонус
    fitness += (maxTime - finishTime) * 25  // бонус за время
    
    if (finishTime < 300):
        fitness += 15000  // очень быстро!
    else if (finishTime < 500):
        fitness += 8000
    else if (finishTime < 800):
        fitness += 3000

// 5. Штраф за низкую скорость
if (avgSpeed < 1):
    fitness -= 1000
else if (avgSpeed < 2):
    fitness -= 500
```

**Условия финиша:**
1. Пройти минимум 75% длины круга
2. Находиться в зоне финиша (< 40 пикселей от старта)

**Баланс компонентов:**
- Выживание: поощряет не врезаться
- Расстояние: стимулирует продвигаться вперёд
- Скорость: предотвращает "ползание"
- Финиш: главная цель (30000+ очков)
- Штрафы: наказывает неэффективное поведение

## 🤖 Telegram Bot интеграция

### Команды бота
| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и приветствие |
| `/play` | Открыть Mini App |
| `/help` | Справка по управлению |
| `/about` | Информация о проекте |
| `/stats` | Статистика пользователя |

### API endpoints

**1. GET /api/bot-info**
- Информация о боте
- Возвращает: name, description, version, webapp_url

**2. POST /webhook/:token**
- Webhook для получения обновлений от Telegram
- Обрабатывает команды и callback queries

**3. POST /api/webapp-data**
- Приём данных от Mini App
- Валидация через HMAC-SHA256
- Сохранение игровых данных

**4. POST /api/save-score**
- Сохранение рекордов пользователя
- Параметры: score, generation, trackName

**5. GET /api/leaderboard**
- Таблица лидеров
- Возвращает топ игроков

### Безопасность
**Валидация WebApp данных:**
```javascript
secretKey = HMAC-SHA256('WebAppData', BOT_TOKEN)
computedHash = HMAC-SHA256(secretKey, dataCheckString)
valid = computedHash === receivedHash
```
