# 🏎️ AI Гонки - Telegram Mini App

Нейросети учатся проходить трассу без столкновений!

## 📱 Возможности

- **Самописная нейронная сеть** (без внешних библиотек)
- **Генетический алгоритм** обучения с 4 методами
- **5 различных трасс** разной сложности
- **Telegram Mini App** интеграция
- **Адаптивный интерфейс** для мобильных устройств

## 🚀 Быстрый старт на вашем ПК

### Шаг 1: Установка зависимостей

```bash
cd ai-racing
npm install
```

### Шаг 2: Создание Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. **Сохраните полученный токен!**

### Шаг 3: Запуск с публичным HTTPS (LocalTunnel)

```bash
npm run tunnel
```

Скрипт автоматически:
1. Запустит HTTP сервер на порту 3000
2. Создаст публичный HTTPS туннель
3. Покажет ваш публичный URL (например: `https://xxx-xx-xx-xxx.loca.lt`)

### Шаг 4: Настройка Mini App в Telegram

1. В @BotFather отправьте `/newapp`
2. Выберите вашего бота
3. Введите название: "AI Гонки"
4. Описание: "Нейросети учатся гонкам"
5. Введите ваш HTTPS URL из шага 3
6. Загрузите иконку (опционально)

### Шаг 5: Добавление токена бота

Отредактируйте файл `.env`:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
WEBAPP_URL=https://ваш-туннель.loca.lt
PORT=3000
```

### Шаг 6: Перезапуск

```bash
# Остановите текущий сервер (Ctrl+C)
npm run tunnel
```

## 🎮 Готово!

Теперь откройте вашего бота в Telegram и нажмите кнопку "🏎️ Играть"!

## 📋 Альтернативные способы

### Вариант 1: Только локальный HTTP (без Telegram)

```bash
npm start
# Откройте http://localhost:3000 в браузере
```

### Вариант 2: Cloudflare Tunnel

```bash
# Установите cloudflared
npm install -g cloudflared

# Запустите сервер
npm start

# В другом терминале:
cloudflared tunnel --url http://localhost:3000
```

### Вариант 3: Самоподписанный SSL (только для тестов)

```bash
npm run ssl    # Генерация сертификата
npm run https  # Запуск HTTPS сервера
```

⚠️ **Важно:** Telegram не принимает самоподписанные сертификаты. Используйте LocalTunnel или Cloudflare.

## ❓ Частые вопросы

### Q: Туннель не работает?
A: Убедитесь, что порт 3000 свободен и у вас есть интернет.

### Q: Telegram не открывает Mini App?
A: Проверьте что URL начинается с `https://` и доступен из интернета.

### Q: Как сохранить прогресс?
A: Прогресс сохраняется в сессии. Для постоянного хранения нужна база данных.
